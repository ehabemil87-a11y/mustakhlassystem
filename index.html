استيراد مستخلصات دفعة واحدة
ارفع ملف Excel بمستخلصات الشهر. الأعمدة المتوقعة: project (اسم المشروع كما هو في تبويب المشاريع — إلزامي) أو code (كود المشروع)، amount (قيمة المستخلص — إلزامي)، notes (ملاحظات — اختياري). تُنشأ كل المستخلصات بحالة «قيد المراجعة» بأرقام تلقائية، ثم تدخل على كل مستخلص لرفع مرفقاته.
إعدادات تنبيهات التأخير
حدّد عدد الأيام المسموح بها لكل مرحلة. بعد تجاوز المدة، يظهر المستخلص كـ «متأخر» ويُنشأ تنبيه تلقائي للجهة المسؤولة. اكتب 0 لتعطيل تنبيه مرحلة معيّنة.
